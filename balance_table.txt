Space Miner Balance Table
========================

Balance algorithm
-----------------
1. Prices stay fixed at the approved values
2. Early items stay unchanged:
   - cursor
   - handMiner
   - laserDrill
3. Later item bonus penalty:
   - starts from autoDrill
   - bonus penalty grows by 5% per tier
   - later items lose more bonus than earlier items
4. Effective bonus formula:
   - adjustedBonus = originalBaseBonus / (1 + penaltyTier * 0.05)
   - if adjustedBonus >= 1, floor to integer
   - preserve strictly descending naked efficiency after flooring
   - if adjustedBonus < 1, keep the original sub-1 bonus so the item is not zeroed
5. Special upgrade costs:
   - bronze = baseCost * 20
   - silver = baseCost * 70
   - gold = baseCost * 250
   - diamond = baseCost * 900
6. Full special set bonus:
   - buying bronze + silver + gold + diamond gives one extra x2 set bonus
   - total max multiplier per item = x32
7. Efficiency curve check:
   - current naked efficiency remains strictly descending after integer flooring
