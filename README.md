# Space Miner

這是一個單頁面的太空採礦 clicker / idle 遊戲。

目前專案結構很輕量：

- `index.html`：頁面結構與 CSS
- `game.js`：全部遊戲邏輯

## 核心玩法

- 點擊中央星球可獲得星能
- 星能可購買商店道具
- 道具會提供每秒星能產出
- 道具數量達到門檻後，可解鎖該道具的特殊強化
- 可開啟自動購買，系統會根據目前評估邏輯自動選擇道具

## 主要資源

目前只有一種資源：

- `星能`

顯示位置：

- 上方大字：目前星能
- 上方小字：每秒星能

## 點擊與被動收益

### 點擊收益

- 基礎點擊收益為 `1`
- `游標礦工` 每個會額外提供 `+0.5` 點擊收益
- `游標礦工` 的特殊強化會再乘上倍率

公式概念：

- `點擊力 = (1 + 游標礦工數量 * 0.5) * 游標特殊強化倍率`

### 每秒收益

每個道具都有：

- `baseCost`
- `baseBonus`
- `count`

每秒收益為所有道具加總：

- `count * baseBonus * 特殊強化倍率`

## 一般道具商店

### 價格成長

每次購買後價格成長公式：

- `目前價格 = baseCost * 1.15 ^ count`

目前在程式中使用大數運算處理，避免後期精度飄掉。

### 商店解鎖條件

一般商店道具不是一開始全部可見。

解鎖條件：

- 當 `目前星能 >= 該道具 baseCost 的 0.5 倍` 時，該道具在商店中出現

### 自動購買推薦邏輯

若開啟自動購買，系統會為每個已解鎖道具計算：

- `等待時間`：以目前每秒星能，要多久才買得起
- `回本時間`：買下後多久回收成本
- `總評估時間 = 等待時間 + 回本時間`

自動購買會選擇：

- `總評估時間最短` 的道具
- 一般道具與目前可購買的特殊強化會一起進入評估

商店 tooltip 中的 CP / 等待 / 總評估文字，只會在勾選自動購買時顯示。

## 特殊強化

每個道具有三階特殊強化：

- 銅
- 銀
- 金
- 鑽石

### 解鎖條件

對應原道具數量達標後才出現：

- `10` 個：解鎖銅
- `30` 個：解鎖銀
- `50` 個：解鎖金
- `70` 個：解鎖鑽石

### 購買規則

- 每一階只能買一次
- 每買一階，該道具效果乘 `x2`
- 可疊加

所以：

- 只買銅：`x2`
- 買銅 + 銀：`x4`
- 買銅 + 銀 + 金：`x8`
- 買滿銅 + 銀 + 金 + 鑽石：`x16`

### 顯示規則

- 特殊強化只顯示在商店上方的 `特殊強化` 區塊
- 若目前一個特殊強化都尚未解鎖，整個區塊會隱藏
- 已購買的特殊強化會保留在原位置並顯示 `已購買`

### 光暈規則

特殊強化會給原道具圖示光暈：

- 銅：銅色
- 銀：銀色
- 金：金色
- 鑽石：亮青藍色

若同一道具買了多階：

- 只顯示最高階顏色

## 畫面上的道具表現

### 中央區塊

- 沒有任何道具時，中央道具列整個隱藏
- 有道具後才顯示
- 中央區只顯示一般道具，不顯示特殊強化道具

### 軌道顯示

- `游標礦工` 會繞著星球旋轉
- 超過 `30` 個時會進入第二圈

### 側邊道具列

- 顯示玩家目前擁有的各種一般道具
- 沒有任何道具時整個隱藏

## tooltip 系統

目前商店 tooltip 使用 JS 自訂浮層，不用原生 `title`。

好處：

- 顯示更快
- 不容易抖動
- 不會被商店容器裁切
- 一般商店與特殊強化商店共用同一套浮層

## 數字顯示

### 顯示模式

左上角有 `星能顯示單位` 勾選框。

未勾選時：

- 使用一般數字 / 科學記號顯示

勾選時：

- 上方目前星能
- 上方每秒星能
- 商店價格
- 特殊強化價格

都會使用中文大數單位顯示。

### 已支援的單位

- 萬
- 億
- 兆
- 京
- 垓
- 秭
- 穰
- 溝
- 澗
- 正
- 載
- 極

後期為避免字串太長：

- 到較高量級後會進入精簡顯示，只保留前兩級

## 大數系統

目前已經不是單純用 JS 原生 `Number` 直接跑主資源。

### 已改成大數處理的部分

- `game.score`
- 道具購買價格
- 每秒收益累積
- 商店購買判斷
- 自動購買判斷中的價格比較
- 存檔 / 讀檔中的主資源

### 實作方式

`game.js` 內建了一個輕量 `BigNum` 類別，採用：

- `mantissa`
- `exponent`

類似科學記號的方式處理大數。

目標是：

- 保持目前遊戲邏輯不變
- 避免數字大到 `京 / 垓 / 極` 時精度明顯錯亂

## 存檔機制

目前存檔使用瀏覽器 `localStorage`。

鍵名：

- `spaceMinerSave`

### 存檔內容

- 目前星能
- 總點擊次數
- 自動購買是否開啟
- 星能單位顯示是否開啟
- 各道具數量
- 商店解鎖狀態
- 特殊強化購買 / 解鎖狀態

### 存檔時機

- 遊戲每 `10` 秒自動存一次
- 切換 `自動購買` 勾選狀態時立即存檔
- 切換 `星能顯示單位` 勾選狀態時立即存檔

### 注意事項

這是本地存檔，不是帳號雲端存檔。

所以：

- 同一瀏覽器、同一網站來源通常會保留進度
- 清除瀏覽器站點資料後會消失
- 換瀏覽器 / 換裝置不會同步

## 目前已存在的輔助功能

- `重置遊戲`
- 自動購買
- 星能單位切換
